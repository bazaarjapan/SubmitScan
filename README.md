# SubmitScan

Googleスプレッドシートとバーコードスキャナーを使って、提出物の提出状況を確認するツールです。名簿からバーコードを作成・印刷し、読み取ったバーコードを名簿と照合できます。

## スプレッドシートをコピーして使う

次のリンクをクリックし、Googleアカウントでスプレッドシートをコピーしてください。

**[SubmitScanのスプレッドシートをコピーする](https://docs.google.com/spreadsheets/d/1U6Br8tAzEUkoBWoeX1OK-qbUj8KS0w7YcqHhAmQeEI4/copy)**

コピーしたスプレッドシートを開き直すと、メニューバーに「バーコード」が表示されます。初回実行時にGoogleの承認画面が表示された場合は、内容を確認して許可してください。

## 基本的な使い方

1. 「バーコード作成」シートのA～C列へ名簿情報を入力します。
2. 「バーコード」→「バーコード作成」を実行します。
3. 全件を印刷する場合は、通常の1セル選択のまま「バーコード」→「印刷用シートを作成」を実行します。一部だけを印刷する場合は、「バーコード作成」シート上で対象の2行以上を選択してから実行します。
4. 作成された「バーコード印刷」シートを「ファイル」→「印刷」から印刷します。
5. 提出確認時は「読み込み」シートのA1を選び、半角英数入力モードでバーコードを読み取ります。
6. 「バーコード」→「チェック」を実行すると、名簿に日付列と提出結果が記録されます。
7. 次の読み取り前に「バーコード」→「入力初期化」を実行します。

## 印刷と読み取りのヒント

- 印刷倍率は「100%」または「実際のサイズ」を使用してください。
- 最初に1枚だけ試し刷りし、使用するスキャナーで読み取れることを確認してください。
- バーコードを拡大・縮小した画像として貼り直さないでください。

## 利用上の注意

- 名簿や提出状況を扱うため、共有範囲とアクセス権を適切に設定してください。
- バーコード画像の生成には外部サービス `webarcode.com` を利用します。所属組織の個人情報・外部サービス利用方針を確認してから使用してください。
- 本番の名簿を変更する前に、少人数のテストデータで一連の操作を確認してください。
